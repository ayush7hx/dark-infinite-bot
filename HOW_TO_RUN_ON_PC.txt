=== HOW IT WORKS (SMART MODE) ===
====================================================

* Jab Replit bot ONLINE hai:
  -> PC bot wait karega (60s intervals mein check karta rahega)

* Jab Replit bot OFFLINE hota hai:
  -> PC bot automatically detect karega aur online aa jaayega

* Multiple PCs:
  -> PC lock system hai — ek time pe sirf ek PC bot chalayega
  -> Doosra PC wait karta hai jab tak pehla PC active hai

* Auto-update:
  -> Har start pe Replit se latest code check hota hai
  -> Agar koi change hai to automatically update ho jaata hai
  -> Token safe rehta hai update ke baad bhi

* Background mein chalta hai:
  -> PC screen band hone pe bhi chalega
  -> System shutdown tak active rahega
